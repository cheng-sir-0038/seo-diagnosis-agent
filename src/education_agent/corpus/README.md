# TAL-SCQ5K 中文数学题

`tal_equations.jsonl` 收录 50 道标有「一元一次方程」相关知识点的单选题。选题时过滤重复、依赖图片、标签明显不符和格式不完整的样本。LaTeX 的显示格式经过转换。答案与解析沿用原发布数据。

每行保留 `queId`（`id`）、原题号（`original_id`）、数据分组和文件行号，可追溯到固定版本的原始题目。感谢 TAL-SCQ5K 作者（math-eval）发布该数据集。上游数据许可为 MIT，发布说明中标注的中文数据版本为 2023-07-07。[上游仓库与许可声明](https://github.com/math-eval/TAL-SCQ5K/blob/8a66d6e14c65ba002beda39747e6b7c43bd2d472/README.md#licensing-information) · [数据许可](LICENSE-TAL)
